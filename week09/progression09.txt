สิ่งที่ฉันได้เรียนรู้คือ : 
1.  .value.trim().length === 0 คือเช็กว่าผู้ใช้ไม่ได้พิมพ์อะไร
    ถ้าว่างก็ให้ขึ้นข้อความสีแดงว่า "your fname is empty” หรือ “your lname is empty”
2.  ใส่ true หมายถึง “Capturing phase” คือเหตุการณ์ที่เริ่มจากข้างนอกสุด (body) -> div -> button
    ถ้าไม่ใส่ true จะเป็น “Bubbling phase” คือเริ่มจากข้างในไปข้างนอก
3.  แบบที่ 1 จะไม่ทำงาน เพราะเป็นคนละ function กัน
    แบบที่ 2 ลบได้ เพราะมี function ชื่อเดียวกัน
4.  เป็น alert ขึ้นมาให้กรอกชื่อ และยืนยัน ถึงจะขึ้นสำเร็จ
