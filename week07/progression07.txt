สิ่งที่ฉันได้เรียนรู้คือ : 
เวลาเข้าถึงข้างใน <div> จะมี 2 แบบ
    1.ใช้ childNodes จะดึงมาหมดเลย ทั้ง element, ช่องว่างที่เป็น text, comment
      เป็น NodeList มันเหมือนลิสต์ที่ใช้ forEach เดินดูได้
    2.ใช้ children จะเอามาเฉพาะ แท็ก element เท่านั้น เช่น <p> ได้เป็น HTMLCollection ซึ่งเปลี่ยนแปลงตาม DOM ตลอด (dynamic) 
      แต่อันนี้จะใช้ forEach ไม่ได้ ต้องวนลูปแบบ for หรือแปลงเป็น array ก่อน

เวลาเราจะสร้างแท็กใหม่ขึ้นมาเอง มีขั้นตอนแบบนี้
    1. document.createElement("p")  สร้างแท็กเปล่า ๆ <p></p>
    2. .setAttribute("id","p5") ใส่ attribute เช่น id
    3. .textContent = "Hello" ใส่ข้อความในแท็ก
    4. .appendChild() เอาแท็กที่เราสร้าง ไปใส่ใน parent เช่น <body>

innerHTML -> เหมือนเอาข้อความไปเป็นโครงสร้าง HTML จริง ๆ เช่น <i>Hi</i> จะกลายเป็นตัวเอียง
innerText -> จะเอามาเฉพาะข้อความที่มองเห็นบนหน้าเว็บ ถ้า CSS ซ่อนก็ไม่เอามา
textContent -> เอาข้อความทั้งหมด ไม่สนใจว่k0tซ่อนอะไร  <i>Hi</i> จะได้เป็น <i>Hi</i> ทั้งหมด
