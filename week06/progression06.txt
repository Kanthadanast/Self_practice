สิ่งที่ฉันได้เรียนรู้ : 
ในข้อที่ 1 จะเห็นว่า calculate ไม่ได้สนใจเลยว่าจะทำอะไรกับ array แค่ส่งงานให้ compute จัดการแทน เช่นจะ sum จะ max หรือจะ sort ก็แค่ส่งฟังก์ชันที่ต้องการเข้าไป
ในข้อที่ 2 count ถูกเก็บไว้ใน memory แม้ว่า counter จะทำงานเสร็จแล้ว เพราะมันถูกฟังก์ชัน increment ใช้งานอยู่ จะเรียกว่า closure
ในข้อที่ 3 a() return ตัวฟังก์ชัน sum  เพราะเรียก typeof เลยได้ "function"
        b() return ค่า sum(1,5)   typeof จึงเป็น "number"
        c(sum) return ค่า sum แบบตรงๆ ได้เป็นฟังก์ชันเหมือนเดิม
        ฟังก์ชันคือค่าชนิดหนึ่ง ส่งต่อไปมาได้
